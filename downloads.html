Installing or upgrading

Upgrades install over an existing copy and leave your job data alone, but take a backup of your data directory first as a matter of course. If you run Lien Writer from a shared network location or a Citrix / Terminal Server environment, talk to us before upgrading — the order of operations matters when several workstations share one database.

Call or email and we will walk you through it. There is no separate support queue for installations.

The web app

Lien Writer needs nothing installed. Subscribers sign in at app.lienwriter.com. If you run the desktop program today, your jobs, customers, and history can come across — we import them. Talk to us before you start and we will plan the move around your notice deadlines.
